# Demolition Derby

Car-smashing party game for Windows: classic derby, monster truck, and punch buggy with boxing gloves. Solo against AI, or online with up to 6 players.

**Download:** [DemolitionDerby-Windows.zip](https://github.com/tommyoldham/demolition-derby/releases/latest/download/DemolitionDerby-Windows.zip)

Unzip the whole folder and run `DemolitionDerby.exe`. Windows may warn about an unknown publisher: choose More info, then Run anyway.

## Playing online

One person picks Play Online, then Host a Game. Everyone else types the address shown in the host lobby and picks Join Game. All players need the same version.

Over the internet, the host has to forward UDP port 24601 on their router and share their public IP, or everyone can use a tool like Tailscale.
